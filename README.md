# Azure-DevOps-Pipeline-Test-for-Sentinel


## Overview

This repository is used to test and validate Azure DevOps CI/CD pipelines for Microsoft Sentinel content deployment. The objective is to automate the deployment and management of security content such as Analytics Rules, Hunting Queries, Workbooks, Playbooks, and Watchlists using Infrastructure as Code (IaC) principles.

## Purpose

The repository helps:

- Validate Azure DevOps pipeline configurations.
- Test automated deployment of Microsoft Sentinel content.
- Support Detection-as-Code practices.
- Standardise security content deployment across environments.
- Reduce manual deployment effort and configuration drift.
